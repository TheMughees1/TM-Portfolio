# TM Portfolio

A responsive personal portfolio for **Mughees ur Rehman**, built with plain **HTML, CSS, and JavaScript**. It uses static files only—no React, npm, or build step required.

## Live website

[Open TM Portfolio](https://themughees1.github.io/TM-Portfolio/)

## Features

- Responsive layout for desktop and mobile
- Clean editorial styling with a restrained neutral palette and green accent
- Mobile navigation menu and active section highlighting
- About, skills, selected projects, and contact sections
- Project links to live demos and source repositories where available
- Smooth scrolling and reduced-motion accessibility support
- Lightweight static files suitable for GitHub Pages

## Run locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

No installation or build command is required.

## Main files

- `index.html` — page structure and project content
- `style.css` — layout, visual design, and responsive styles
- `script.js` — mobile menu, active navigation, and current year
- `src/assests/` — existing portfolio images and logo
